# MOKKA 沐木選品｜質感生活與香氛品牌電商前台原型

以溫潤米白與深胡桃木色系打造的質感生活與居家香氛選品電商前台原型，採用 **Vite + React + Tailwind CSS v4 + Lucide React** 建置，並預先支援 Cloudflare Pages SPA 路由回退與綠界 ECPay 金流介面預留。

## 功能特色

- **溫潤簡約 RWD 視覺設計**：米白紙感底色搭配深木質字體、襯線標題排版，完整支援手機與桌面螢幕。
- **頂部導覽列**：品牌識別、快速分類跳轉（全部選品／織品噴霧／室內擴香／禮盒組／品牌故事）與即時購物車件數徽章。
- **首頁主視覺與品牌故事**：雜誌感香氛攝影主視覺與三大植萃選品理念。
- **即時分類篩選與互動商品卡**：支援「全部」、「織品噴霧」、「室內擴香」、「禮盒組」即時切換；提供卡片懸停效果、「查看香調」與「快速加入」按鈕。
- **商品詳情彈窗（Modal）**：完整呈現前調／中調／後調三段式香調層次、容量規格、使用建議與數量加入功能。
- **側邊滑出式購物車（Cart Drawer）**：支援增減數量、刪除品項、`localStorage` 狀態保存、自動計算小計運費，以及 **「滿 NT$1,500 免運」動態進度條**。
- **模擬結帳流程**：填寫收件人資訊並選擇「超商取貨付款（7-ELEVEN／全家）」或「信用卡一次付清（綠界 ECPay 預留介面）」，送出後顯示模擬訂單編號完成畫面。
- **Cloudflare Pages 就緒**：內含 `public/_redirects`（`/* /index.html 200`）以支援 SPA 路由回退。

## 本地開發與建置

```bash
npm install
npm run dev
npm run build
```
